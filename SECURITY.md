# Security

This library and service handle patient text. Please report a security problem **privately**,
not in a public issue: use **Report a vulnerability** on this repository's Security tab (GitHub's
private vulnerability reporting). Include what you found, how to reproduce it, and what it could
expose. Don't include real patient details.

You'll get an acknowledgement, and a fix or an explanation, as soon as the maintainers can
manage. This is a small, pre-release project with no guaranteed response time.

A redaction miss (an identifier left in the output) is a limitation rather than a vulnerability
unless it can be triggered deliberately or exposes more than the text sent; see
[docs/LIMITS.md](docs/LIMITS.md). Report misses as ordinary issues, with invented examples only.
